# Handoff: shrink the whole public website (2026-10-29)

**Project:** GIO Kerala (giokerala.org) is being rebuilt from WordPress/Elementor as a Next.js site on Cloudflare (D1 + R2) with an admin dashboard. The public site and admin are in the worktree `C:\dev\gio-kerala-web` (branch `phase-3/website`). The dev site runs at http://localhost:3000.

## What changed
The user asked to "shrink the whole website". Tailwind sizes are in rem, so the site scales from the root font size, which is set only on pages that render `<main data-site>`. The admin keeps the browser default.

| Viewport | Before | Now |
|---|---|---|
| below 1024px (phones, tablets) | 100% (16px) | 93.75% (15px) |
| 1024px and up | 87.5% (14px) | 81.25% (13px) |

Text, spacing, container widths and the sticky-header height (`--header-h` is in rem) all shrink together. Media-query breakpoints do not move.

File: `apps/web/src/app/globals.css`, the "Public-site scale" rule (around line 64). Uncommitted.
