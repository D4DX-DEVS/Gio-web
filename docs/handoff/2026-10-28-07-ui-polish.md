# Handoff: public website UI polish (2026-10-28)

**Project:** rebuild of giokerala.org (Girls Islamic Organization Kerala) from WordPress/Elementor to Next.js 16 (App Router) + Tailwind 4 on Cloudflare Workers (D1 + R2, via OpenNext). Work runs in parallel git worktrees. This task is in `C:\dev\gio-kerala-ui`, branch `phase-4/ui-polish`, based on `integration/demo` (ed6fb1e) plus commit 029fcd2 from `phase-3/website`, applied but not committed. **Nothing is committed yet.**

## What this task did
A design and interaction pass over the public site. Content, URLs, data access, the legacy URL/media layer and the deployment config were not changed. The brand stays blue and red, taken from the old site's Elementor kit; I did not switch to green because the brand assets don't use it.

- **Design tokens** in `globals.css`: shadow scale (card, lift, pop) and an easing curve. Shared CSS classes `card-lift` and `zoom-media` give every clickable card the same hover. Rules for Malayalam stop long words from overflowing and give headings a taller line height. There is now one consistent keyboard focus ring.
- **Header:** the menu marks the current page (`aria-current`), the dropdown is smoother, tap targets are 44px, and the sticky header gets a shadow on scroll (pure CSS). The phone and email in the top bar now have icons.
- **Mobile menu:** now a slide-in drawer built on the native `<dialog>`. Focus is trapped, Escape closes it, the page behind it is inert and can't scroll, and it closes when you navigate. It shows the current page, the contact details and the social links.
- **Homepage:**
  - Under the banner carousel there is now a visible `<h1>` (tagline + "GIO Kerala", both from site settings) and four shortcut tiles (About, News, Events, Gallery). Before, the h1 was screen-reader only.
  - Section spacing is tighter.
  - The poster slider has previous/next buttons.
  - The news and event cards were redesigned.
  - Nothing was invented: no statistics, text or sections that don't exist on the site.
- **Hero carousel:**
  - New controls: pause/play button (WCAG 2.2.2), swipe on touch screens, and it pauses while it has keyboard focus.
  - No autoplay for people who prefer reduced motion.
  - Hidden slides are `inert`.
  - The active slide slowly zooms out (very subtle).
- **Animations:**
  - Sections and cards fade and slide in as you scroll, using CSS scroll-driven animations (`animation-timeline: view()`). Content already on screen is never hidden waiting for JavaScript, browsers without support just show the content, and there is no layout shift.
  - Cards lift on hover and their images zoom gently.
  - Buttons have press states, and modals fade in and out.
  - Everything respects `prefers-reduced-motion`.
- **New reusable components:**
  - `Modal.tsx`: native dialog with focus handling, Escape, backdrop click and scroll lock.
  - `Lightbox.tsx`: full-screen image viewer with arrow keys, swipe, a counter and a caption.
  - `LightboxScope.tsx`: makes the photos inside any content open in the lightbox. Linked images that point to pages keep working as links.
  - `GalleryGrid.tsx`, `ScrollRow.tsx`, `DesktopNav.tsx`.
- **Where the lightbox is used:**
  - The gallery page: every photo opens full size, with a "Read the story" or "View the event" link.
  - Images in post and event bodies, and their featured images.
  - Rich-text sections, unlinked posters and the About image.
  - Without JavaScript, gallery tiles link to the image file.
- **Other pages:**
  - Listing tabs, pagination (44px targets), event cards (upcoming events in red, past events in blue), the event detail sidebar, the documents list and the leader cards were polished.
  - The footer is two columns on mobile.
  - `lang` was added to more Malayalam text.
- Added `data-scroll-behavior="smooth"` on `<html>`. This fixes a Next.js 16 console warning.

**Not added, on purpose:**
- No announcement popup: there is no announcement data in the schema.
- No event "quick view" modal: event detail pages already exist and are better for sharing and SEO.
- No newsletter or registration popups.
- The video stays a click-to-play inline player. Another session is building video cards with a pop-up player.
